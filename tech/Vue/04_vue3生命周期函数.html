1. 什么是生命周期钩子（函数) ​

每个 Vue 组件实例在创建时都需要经历一系列的初始化步骤，比如设置好数据侦听，编译模板，挂载实例到 DOM，以及在数据改变时更新 DOM。在此过程中，它也会运行被称为生命周期钩子的函数，让开发者有机会在特定阶段运行自己的代码。

简单来说：生命周期钩子就是在vue实例创建过程中或更新过程中的某个时间点会自动触发的函数

2. 生命周期的三个阶段及相关的钩子(生命周期函数) ​

创建阶段 (只执行一次) ​

  • beforeCreate

  • created

  • beforeMount

  • mounted

运行阶段 （可以依据数据的变化执行多次） ​

  • beforeUpdate
  • updated

销毁阶段 （最多执行一次） ​

vue3

  • beforeUnmount
  • unmounted

vue2

  • beforeDestroy
  • destroyed

3. 每个生命周期函数的特点 ​

3.1. beforeCreate ​

在组件实例初始化完成之后立即调用

此时，data和methods、computed、watch都还没有初始化，不能访问

js
beforeCreate(){
    console.log('beforeCreate',this.msg);
},
1
2
3

3.2. created ​

在组件实例处理完所有与状态相关的选项后调用

当这个钩子被调用时，以下内容已经设置完成：响应式数据、计算属性、方法和侦听器。然而，此时挂载阶段还未开始，不能访问DOM,但可以访问数据

js
created(){
    console.log('created',this.msg);
},
1
2
3

3.3. beforeMount ​

在组件被挂载之前调用

当这个钩子被调用时，组件已经完成了其响应式状态的设置，但还没有创建 DOM 节点。它即将首次执行 DOM 渲染过程

js
beforeMount(){
    let info = document.querySelector(".info");
  	 console.log("beforeMount", info);  // null
},
1
2
3
4

3.4. mounted ​

在组件被挂载之后调用

  • 所有同步子组件都已经被挂载
  • 其自身的 DOM 树已经创建完成并插入了父容器中
js
mounted(){
    //1. 网络(接口)请求 2. 访问dom (nextTick使用和不使用的区别)  3. 事件监听
    let info = document.querySelector(".info");
    console.log("mounted", info);
},
1
2
3
4
5

3.5. beforeUpdate ​

在组件即将因为一个响应式状态变更而更新其 DOM 树之前调用

当且仅当data被修改时才触发这个生命周期函数，但此时仅仅是数据被修改，页面还未更新。 如果修改的data数据并没有在模板中使用，也不会触发更新

js
beforeUpdate(){
    console.log('beforeUpdate',this.msg);
    console.log('beforeUpdate');
},
1
2
3
4

3.6. updated ​

在组件因为一个响应式状态变更而更新其 DOM 树之后调用

  • 父组件的更新钩子将在其子组件的更新钩子之后调用

  • 这个钩子会在组件的任意 DOM 更新后被调用，这些更新可能是由不同的状态变更导致的。如果你需要在某个特定的状态更改后访问更新后的 DOM，请使用 nextTick() 作为替代

  • 不要在 updated 钩子中更改组件的状态，这可能会导致无限的更新循环！

js
updated(){
    console.log('updated');
},
1
2
3

3.7. beforeUnmount ​

在一个组件实例被卸载之前调用

当这个钩子被调用时，组件实例依然还保有全部的功能

js
beforeUnmount(){
    console.log('beforeUnmount');
},
1
2
3

3.8. unmounted ​

在一个组件实例被卸载之后调用

  • 其所有子组件都已经被卸载
  • 所有相关的响应式作用 (渲染作用以及 setup() 时创建的计算属性和侦听器) 都已经停止
  • 可以在这个钩子中手动清理一些副作用，例如计时器、DOM 事件监听器或者与服务器的连接
js
unmounted(){
    console.log('unmounted');
}

  • 和vue3比较，只有最后两个生命周期发生变化，
js
// vue3
beforeUnmount()		unmounted()
// vue2
beforeDestroy()     destroyed()

5. 练习代码 ​

html
<!DOCTYPE html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <meta http-equiv="X-UA-Compatible" content="ie=edge" />
    <title>Document</title>
  </head>

  <body>
    <!-- 
        生命周期函数： 在vue实例化过程中的某个时间点会自动触发的函数

        创建阶段
            beforeCreate
            created
            beforeMount
            mounted
        运行阶段 
            beforeUpdate
            updated
        销毁阶段
            beforeUnmount
            unmounted
     -->
    <div id="app">
      <p class="info">{{msg}}</p>
      <ul>
        <li v-for="item in color">{{item}}</li>
      </ul>
      <p><button @click="changeData">更改msg</button></p>
    </div>

    <hr />
    <script src="./js/vue3.js"></script>
    <script>
      const { createApp } = Vue;
      const app = createApp({
        data() {
          return {
            msg: "hello",
            num: 1,
            color: ["red", "green"],
          };
        },
        methods: {
          changeData() {
            this.msg = Date.now(); //触发更新
            // this.num = Date.now(); //不会触发更新，因为虽然是data数据，可是没有在模板中使用
          },
        },
        beforeCreate() {
          console.log("beforeCreate", this.msg);
        },
        created() {
          console.log("created", this.msg);
        },

        beforeMount() {
          let info = document.querySelector(".info");
          console.log("beforeMount", info);
        },

        mounted() {
          let info = document.querySelector(".info");
          console.log("mounted", info);
        },

        beforeUpdate() {
          let info = document.querySelector(".info");
          console.log("beforeUpdate", this.msg, info.innerHTML);
        },

        updated() {
          let info = document.querySelector(".info");
          console.log("updated", this.msg, info.innerHTML);
        },

        beforeUnmount() {
          console.log("beforeUnmount");
        },

        unmounted() {
          console.log("unmounted");
        },
      });

      app.mount("#app");
    </script>
  </body>
</html>

6. 模板引用 ​

虽然 Vue 的声明性渲染模型为你抽象了大部分对 DOM 的直接操作，但在某些情况下，我们仍然需要直接访问底层 DOM 元素。要实现这一点，我们可以使用特殊的 ref attribute

它允许我们在一个特定的 DOM 元素或子组件实例被挂载后，获得对它的直接引用

挂载结束后引用都会被暴露在 this.$refs 之上

html
<div id="app">
    <p><input type="text" ref="search" /></p>
    <ul>
        <li v-for="item in [1,2,3]" ref="goods">{{item}}</li>
    </ul>
</div>

js
const app = createApp({
    //挂载后访问dom
    mounted() {
        // {search: 搜索框DOM, goods:[li列表]}
        console.log(this.$refs) 
        // 搜索框自动获取输入焦点
        this.$refs.search.focus()
    },
})
