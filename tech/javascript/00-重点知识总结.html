4. 重要算法的理解---理解并能够手写 ​

  • 冒泡排序

    规则：从左到右，数组中相邻的两个元素进行比较，将较大的放到后面。

    规律：冒泡排序每一轮排序，都可以找出一个较大的数，放在正确的位置。

    比较的轮数 = 数组长度 - 1;

    每一轮比较的次数 = 数组长度 - 当前的轮数

    js
    var score = [89, 34, 56, 67, 90, 23, 68, 100, 85, 12]
for (var j = 0; j < score.length - 1; j++) {
  // j表示第几轮
  console.log('第' + (j + 1) + '轮开始')
  for (var i = 0; i < score.length - (j + 1); i++) {
    if (score[i] > score[i + 1]) {
      var temp = score[i]
      score[i] = score[i + 1]
      score[i + 1] = temp
    }
    console.log(score) // [34,89,56,67,90,23]
  }
  console.log('第' + (j + 1) + '轮的结果是', score)
}

4.1 秒杀倒计时 ​

js
var clock = document.querySelector('.clock')

//倒计时  结束时间是： 2023/3/24 8:00结束
// 剩几天几小时几分钟几秒

// 25h  --- d = 1天   h = 1小时
function countdown() {
  var startTime = new Date().getTime()
  var endTime = new Date('2023/3/25 17:00:00').getTime()
  var interval = (endTime - startTime) / 1000 // 秒

  var d = parseInt(interval / 60 / 60 / 24) //  3
  var h = parseInt((interval / 60 / 60) % 24) // 243  / 24 = 10.
  var m = parseInt((interval / 60) % 60)
  var s = parseInt(interval % 60) // 剩余时间是85s , 秒位应该显示25

  if (h < 10) h = '0' + h
  if (m < 10) m = '0' + m
  if (s < 10) s = '0' + s

  clock.innerText = '剩余' + d + '天 ' + h + ':' + m + ':' + s
}
countdown()
setInterval(countdown, 1000)

2. 浮点运算精度丢失的问题 ​

浮点数就是有小数位的数值

js
0.1 + 0.2 // 本来结果是0.3 实际 0.30000000000000004
1

  • 原因

    浮点数运算时会造成精度丢失问题，原因是十进制的浮点数在运算时要先转为二进制，而二进制就造成精度丢失

  • 解决方案

    方案一： 先把浮点数乘于10的n次方，转为整数， 计算完毕后再除以10的n次方

    js
    //直接处理浮点数的运算，结果精度丢失
var num1 = 6.8 - 5.6
console.log(num1) // 1.2000000000000002
var num2 = 1.2
console.log(num1 == num2) // false

// 解决方案
var num1 = (6.8 * 10 - 5.6 * 10) / 10
console.log(num1) // 1.2
console.log(num1 === 1.2) //true
