Node.js 的主要特点 &ZeroWidthSpace; 事件驱动 Node.js 使用事件驱动模型,当某个操作完成后会触发一个事件来通知你,你可以编写处理该事件的回调函数。 非阻塞 Node.js 使用非阻塞 I/O,也就是说 Node.js 大部分的时间都在空闲的状态,等待 I/O 操作完成后才会执行其他操纵,这使得 Node.js 高效又轻量。 单线程 Node.js 使用单线程模型,也就是说你无论启动多少异步操作,都只会使用一个线程来执行相应的回调。这避免了多线程之间的切换开销,使得 Node.js 可以处理大量并发请求。 模块化 Node.js 支持 JavaScript 模块化,我们可以使用 require() 来加载模块,使用 exports 或 module.exports 来导出模块中的内容。 包管理 Node.js 使用 NPM(Node Package Manager) 来管理模块包,我们可以很方便地下载或上传开源模块包。 3. 安装NodeJS &ZeroWidthSpace; 下载： &ZeroWidthSpace; ​ NodeJS中文网： http://nodejs.cn/ ​ 注意：14以上版本只有win8以上才支持 安装 &ZeroWidthSpace; ​ 双击安装包，根据提示安装 检测是否安装成功 &ZeroWidthSpace; 打开命令行窗口： 在任意位置结合Shift右键： 在此处打开命令窗口即可 在vscode中打开终端： Ctrl + ` 输入 node -v, 如果显示node的版本号，即表示安装成功 npm -v (npm是node自带的包管理工具) 注意：如果在vscode中不能运行npm,则输入 set-ExecutionPolicy RemoteSigned 4. 安装淘宝镜像 &ZeroWidthSpace; 也就是安装cnpm 从npm网站上安装 cnpm包 js//-g表示全局安装 npm i cnpm -g 12 直接从淘宝镜像安装cnpm npm install -g cnpm --registry=http://registry.npm.taobao.org 1 测试是否安装成功 cnpm -v 1注意：如果安装成功后，在vscode中不能运行cnpm,则输入 set-ExecutionPolicy RemoteSigned 5. 初始化node项目 &ZeroWidthSpace; 生成package.json这个node项目的配置文件 逐步设置配置文件 jsnpm init 1 快速生成配置文件 jsnpm init -y 1 6. 运行node文件 &ZeroWidthSpace; 创建一个nodejs文件 js// index.js console.log('I am NodeJS') 12 在命令行窗口输入 node命令运行文件 jsnode index.js 1 结束执行： ctrl + c 清屏： cls 如果js文件有改动，需要重新执行 7. nodemon的安装和使用 &ZeroWidthSpace; 作用： 可以监听js的变化，并重启服务 安装 jsnpm install nodemon -g // (global,全局安装) nodemon -v //查看nodemon版本，显示版本即安装成功 12 使用 jsnodemon 文件名 1文本发生变化会自动重启服务 nodemon 是一个 Node.js 应用的自动重启工具，主要用于 开发环境，可以在文件发生变更时 自动重启 Node.js 服务器，避免手动停止 &amp; 重新启动，提高开发效率。
